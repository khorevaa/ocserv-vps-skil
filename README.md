# Скилл для развёртывания ocserv на VPS

Компактный скилл Codex для установки и эксплуатации [khorevaa/ocserv-vps](https://github.com/khorevaa/ocserv-vps) на VPS с Debian или Ubuntu.

Runtime, Docker-образы, настройка firewall и сертификатов, транзакционные обновления и веб-панель теперь находятся в репозитории `ocserv-vps`. Здесь остаётся только сценарий для ИИ: проверить сервер, установить закреплённый релиз менеджера, развернуть VPN, проверить результат и при необходимости установить закрытый UI.

## Возможности

- read-only проверка VPS по SSH
- установка стабильного релиза менеджера по явному тегу
- автоматическое развёртывание VPN с явным разрешением на изменение firewall и перезапуск
- статус, логи, пользователи, обновление, откат и удаление через `ocserv-vps`
- опциональная установка и обновление закрытой веб-панели
- безопасная передача VPN-реквизитов и UI-секрета без публикации в чате

UI устанавливается только по явному запросу. Обычное развёртывание ставит только VPN.

## Установка в Codex

```text
$skill-installer install https://github.com/khorevaa/ocserv-vps-skil/tree/develop/skills/ocserv-vps
```

Примеры запросов:

```text
$ocserv-vps разверни VPN на моём VPS
$ocserv-vps разверни VPN и закрытую панель управления
$ocserv-vps проверь сервер и обнови ocserv
```

Полный workflow и правила безопасности находятся в [инструкции скилла](skills/ocserv-vps/SKILL.md).

## Границы репозитория

Не добавляйте сюда сборку ocserv, Dockerfile, серверные deployment-скрипты или исходники UI. Такие изменения должны выполняться в [khorevaa/ocserv-vps](https://github.com/khorevaa/ocserv-vps); этот репозиторий остаётся тонким слоем ИИ-оркестрации.
