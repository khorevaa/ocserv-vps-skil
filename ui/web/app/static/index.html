VPN-доступ

Добавить пользователя

Начните с буквы или цифры; далее допустимы точка, @, дефис и подчёркивание.

Надёжный пароль будет создан сервером и показан один раз.

VPN-доступ

Изменить пароль

Для пользователя будет создан новый пароль.

Текущий пароль сразу перестанет работать. Это действие нельзя отменить.

Активное подключение

Отключить пользователя?

Сеанс пользователя будет завершён. Пользователь сможет подключиться снова с действующим паролем.

Системная операция

Перезапустить ocserv?

Все активные VPN-подключения будут разорваны. Docker автоматически запустит ocserv снова; панель дождётся восстановления сервиса.
